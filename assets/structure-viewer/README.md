# 3D 结构查看器（独立应用）

一个独立于智能计算平台的小工具：上传 POSCAR / CIF，在浏览器里 3D 查看原子、成键与晶胞。

## 多类型数据集查看器

`dataset-viewer/` 是并入 CalcGO 主应用的数据集查看器构建源，不再需要单独监听端口。它使用 Three.js 渲染原子/轨迹和 WebGL2 体数据，使用本地打包的 VTK.js 渲染 CAE 的 VTP 网格。构建命令：

```powershell
cd structure-viewer/dataset-viewer
pnpm install
pnpm exec vite build
```

产物写入 `calcgo/web/viewer_runtime/viewer.js` 和 `viewer.css`，由 `/api/viewer/runtime/*` 在同一 CalcGO 服务端口提供。

## 功能

### 结构加载
- 支持 POSCAR（VASP）与 CIF，可点击选择、整页拖放、直接粘贴结构文本
- 含多个结构块的 CIF 可在页面上选择要加载第几个
- 内置 4 个样例：金刚石 Si（8 原子常规晶胞）、水分子、金红石 TiO₂、ZrO₂ 萤石
- 文件过大或原子数超限时给出明确提示（默认上限 15000 原子）
- 一键“导出离线 HTML”：把渲染引擎、样式和当前结构数据全部内嵌成单个 HTML（约 0.8 MB），
  发给客户后双击即可本地查看/旋转/换主题，无需安装 Python 或启动服务

### 成键
- 按共价/原子半径自动判断（考虑周期镜像），键两端各取一端原子颜色
- 键长容差 1.00–1.40 **拖动实时预览**，无需重新上传解析
- 只看特定元素对（如只看 Zr-O、隐藏 Zr-Zr），切换结构时自动清空旧筛选
- 候选键段按空间线段去重：同一条键只算一次，周期镜像形成多条键时也不丢

### 显示与风格
- 6 个一键风格预设：专业白底 / 深色科技 / 期刊哑光 / 金属质感 / 论文插图 / 演示大片
  （整套切换背景、材质、光照、描边与多面体）
- 配色方案：标准 CPK 元素色（覆盖全部 118 个元素，Pd/Pt 等不再共用灰白兜底色）/
  柔和粉彩 / 单色（论文图）
- 显示模式：球棍 / 空间填充 / 棍状
- 原子大小、键粗细滑条；晶胞框开关
- 进阶光影滑条（可折叠，默认收起）：光照强度 / 曝光 / 粗糙度 / 金属感 / 环境反射 /
  环境亮度 / 原子描边 / 辉光 / 暗角 / 空气雾气，拖动即时生效
- 配位多面体：关闭 / 金属中心 / 全部元素（半透明多面体显示配位环境）
- 背景：渐变 / 纯色 / 透明（透明模式导出带 alpha 的 PNG，方便贴到 PPT 或论文里）
- 球体精度：快速 / 标准 / 精细（结构大时用“快速”更流畅）
- VESTA 式视角预设：适应视图 / 沿 +a、-a、+b、-b、+c、-c 晶轴方向观察
- 导出画质可选当前 / 2× 高清 / 3× 超清：导出走与画面完全相同的渲染通道并超采样，
  晶胞框与原子描边都是实时绘制的几何体，放大后不会出现锯齿毛刺
- “周期镜像”开启后不是只补“半根键”的镜像球，而是把晶胞边界附近的镜像原子连同它们
  在相邻晶胞里的完整成键一起补齐，晶胞边缘不再出现连接残缺的原子；
  结构特别大时会自动降级为轻量补全并给出提示
- 大体系自动优化：原子多时自动降低实时预览分辨率，导出仍按全分辨率渲染
- 原子悬停/点击显示元素、序号、坐标（含周期镜像标注）
- 元素配色图例、当前文件名与键数角标、一键重置视角、PNG 截图导出
- **测距 / 测角**：画布左下角一键切换，依次点 2 / 3 个原子，给出距离（Å）或键角（°），
  同时在 3D 场景里画出青色辅助线；换结构/换帧自动清除上一组测量点
- **反应路径回放**（CI-NEB / MD 逐帧）：单文件 HTML 内嵌帧数据，提供播放/暂停、
  帧滑条、相对能量小图，←/→ 键逐帧查看；主应用的任务结果页可直接打开

### 渲染体验
- three.js PBR 渲染管线：程序化环境反射 + ACES 色调映射 + 4×MSAA + 辉光/暗角/雾气，
  原子为真实球体、键与晶胞框为圆柱几何，观感接近 VESTA / 专业渲染图
- 自由视角：轨道旋转没有“头顶/脚底死区”，转到任何角度都不会卡住；
  主光/补光/轮廓光跟随相机，旋转过程光影稳定，不会越转越亮
- WebGL 场景只创建一次：调整风格/容差/筛选不会重置相机、不重建画布
- 解析只发生一次：服务端下发原子坐标与候选键段，容差与筛选全在浏览器完成
- 周期边界一致性：镜像原子与键按同一套晶格平移规则生成，键两端都有完整的球；
  关闭周期镜像时显示单晶胞，但正好落在面/棱/角上的原子会按“闭合晶胞”
  补到其它边界位置并接上跨边界键，不会出现“半个原子”
- 晶胞框开关只影响晶胞显示，不会改变成键——两者走各自独立的刷新路径

## 启动

双击 `run.bat`，或命令行：

```powershell
cd structure-viewer
pip install -r requirements.txt   # 首次运行先装依赖
python server.py                  # 默认 http://127.0.0.1:8090
```

启动说明：
- 默认只监听本机 `127.0.0.1`；如需局域网访问加 `--host 0.0.0.0`
- 端口被占用会自动向后找空闲端口并提示实际地址
- 启动约 1 秒后自动打开浏览器；不需要可加 `--no-browser`
- 依赖：Python 3.10+，详见 `requirements.txt`（pymatgen、fastapi、uvicorn、python-multipart）
- three.js 与所需 addons 已本地打包（`static/vendor/`），无需联网

## 目录结构

```text
structure-viewer/
  server.py            # FastAPI 解析服务（解析 + 候选键段计算）
  run.bat              # Windows 一键启动
  requirements.txt     # Python 依赖
  test_ui.py           # Playwright 自动化测试（可选）
  static/
    index.html         # 前端页面
    style.css          # 页面样式
    app.js             # 交互、成键过滤、风格与视觉参数控制
    viewer3d.js        # three.js 渲染引擎（原子/键/晶胞/多面体/特效/导出）
    vendor/            # 本地打包的 three.js 与 addons（无需联网）
```

## API

`POST /api/parse`（multipart `file`，可选 `index` 用于多结构 CIF）：

返回：
- `atoms`：紧凑数组（`el/x/y/z/r`，坐标为笛卡尔 Å，`r` 为键判断所用半径）
- `cell`：晶胞行向量矩阵
- `segments`：预计算候选键段（`i/j/d/dx/dy/dz`，已按空间线段去重；容差由前端过滤）
- `formula / reduced_formula / n_atoms / volume / density`
- `blocks / n_blocks`：CIF 多结构块信息

`GET /`：前端页面

`POST /api/export`（JSON：`name` + 已解析的 `data`）：返回单文件离线 HTML

`POST /api/export_trajectory`（JSON：`name` + `frames:[{label, energy, poscar}]`）：
返回带播放器的单文件 HTML；帧数据只用于显示，不做能量计算。

```powershell

```

测试覆盖：样例加载、容差实时变化、风格预设切换不重建画布、只看键筛选、PBC 开关、
闭合晶胞边界原子完整性、晶胞开关不影响成键、视角预设、高清 PNG 导出、
离线 HTML 本地打开、多结构 CIF 切换与页面无横向溢出。
